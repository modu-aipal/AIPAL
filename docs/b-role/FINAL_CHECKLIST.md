## 0. 이 문서의 사용법

### 0.1 단위 체크리스트와의 차이

| | 단위 체크리스트 (WORK_UNITS) | **최종 체크리스트 (이 문서)** |
|---|---|---|
| 시점 | 각 단위 구현 직후 | 전체 완료 후 제출 직전 |
| 범위 | 그 단위 하나 | **B 전체 + A·C와 함께 도는지** |
| 관점 | "이 질문이 풀리는가" | "**숫자가 C와 같은가 · 지어내지 않는가 · 막을 것을 막는가**" |
| 환경 | 로컬 `pytest`, 로컬 포트 | **공개 주소(ngrok) + 본 주소(Vercel) 경유** |

### 0.2 수행 규칙

1. **공개 주소로 수행한다.** ngrok 주소와 A 본 주소(aipal-sangkwon-pulse.vercel.app) 경유 모두. 로컬에서만 된 것은 근거가 되지 않는다.
2. **먼저 서버가 최신 main인지 본다.** 로컬 `git log -1`이 main 최신 커밋과 같고 서버를 그 뒤에 재시작했는지 확인한다.
3. **숫자는 C 정답표·직접 계산으로 대조한다.** "그럴듯해 보인다"는 통과가 아니다.
4. **질문은 말투를 바꿔서 여러 번 묻는다.** 같은 뜻 3가지 이상.
5. **실패 항목은 등급을 매겨 기록한다.** (§0.3)
6. 이 서버에는 계정·저장 데이터가 없다. 로그인·권한 항목은 해당 없음으로 적고, 대신 **API 키·프롬프트 주입·모델 출력 신뢰·지어낸 숫자**를 본다.

### 0.3 결함 등급과 판정

| 등급 | 정의 | 처리 |
|---|---|---|
| **Blocker** | C와 다른 숫자를 맞다고 답함, 지어낸 숫자, 키 없이 호출 가능, 키·비밀값 노출, 서버 시연 불가 | **1건이라도 있으면 제출 불가** |
| **Major** | 질문 뜻과 다른 답, 한계·기준을 잘못 밝힘, 주요 질문이 막힘, 지원 질문이 오류 | 수정 후 재점검 |
| **Minor** | 문구·사소한 표현, 드문 표현을 못 알아들음 | 기록만 하고 제출 후 처리 가능 |

> Part C(보안·무결성) 실패는 기본적으로 Blocker로 본다. Minor로 내리려면 근거를 기록한다.

### 0.4 판정

```
Blocker 0건  AND  Major 0건  →  제출 승인
그 외                        →  제출 보류
```

## AI 활용 · 디버깅 사례 (B)

### 사례 1 — "유망한"이 "망한"으로 읽힘
- **현상**: "홍대는 유망한 상권이야?"를 위험(폐업) 질문으로 해석했다.
- **원인**: 위험 표현을 낱말 "망한"이 포함되는지로 찾았다. "유망한" 안에도 "망한"이 있다.
- **수정**: 앞 글자를 확인하는 정규식(lookbehind)으로 "유망·희망"을 제외했다.
- **재검증**: 위험·전망 표현 테스트에 "유망한"·"희망적인" 사례를 추가했다 (`tests/test_bot_questions.py`).
- **AI 활용 포인트**: 모델이 아니라 규칙이 낸 오류였다. 낱말 포함 검사는 짧은 낱말일수록 다른 말에 숨어 있을 수 있어 반례 질문을 평가셋에 넣어 둔다.

### 사례 2 — 숫자는 맞는데 질문의 뜻이 달랐던 N8 (C가 찾음)
- **현상**: "전년 같은 분기 대비"를 물었는데 전 분기 대비(+10.3%)로 답했다. 정답은 +4.8%.
- **원인**: 증감 기준을 요청에 명시하지 않고 항상 전 분기를 기준으로 계산했다.
- **수정**: 전년 대비 표현을 인식해 기준 기간을 요청에 명시하고, 답변에 어떤 기준인지 밝혔다 (PR #28).
- **재검증**: 이태원 2025Q4 +4.8%가 C 정답표와 같다. C의 `pearl_eval.py` 재실행은 제출 직전에 한다.
- **AI 활용 포인트**: 검증은 숫자와 질문의 뜻 둘 다 봐야 한다는 C의 지적 그대로다.

### 사례 3 — 설명 문구가 분석 질문을 가로챔 (C가 찾음)
- **현상**: "성수 행정동별 매출 보여줘"가 데이터 설명 문구로 답해졌다.
- **원인**: "행정동" 같은 낱말 하나로 설명 주제가 반응했다.
- **수정**: 분석어(매출·순위·점포 수…)가 있고 묻는 말(뭐·언제·어디·왜…)이 없으면 설명을 건너뛰는 게이트를 넣었다 (PR #22).
- **재검증**: C가 재현 질문 4개 모두 계산으로 넘어가는 것을 다시 확인했다 (2026-11-24).

## 1. 분할 원칙

| 규칙 | 내용 |
|---|---|
| **R1. 테스트로 확인 가능** | 단위가 끝나면 `pytest`와 질문 예시로 확인할 수 있다 |
| **R2. 모델 없이도 확인** | 질문 해석은 모델 없이(`--rules-only`) 재현된다 |
| **R3. 숫자는 C 그대로** | B 단위는 숫자를 만들지 않는다. 숫자 확인은 C 정답표·직접 계산과 대조 |
| **R4. 규격 변경은 문서와 함께** | 응답이 바뀌면 `docs/DASHBOARD_API.md`를 같이 고친다 |
| **R5. 완료 조건은 관찰 가능** | "만들었다"가 아니라 "이 질문을 하면 이 답이 나온다" |
| **R6. A·C 불가침** | `dashboard/`, `calc_engine/`은 수정하지 않는다. 필요하면 이슈·문서로 요청 |

완료 조건을 **실제로 보고** 확인해야 완료다. 하나라도 미확인이면 🔄로 남긴다.

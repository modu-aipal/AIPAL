## README의 C 부분

### 기여 — C 이성균
- 공공데이터 준비와 **정의 확정**: '당월 매출'이 분기 3개월 합계인지 등 애매한 부분을 제공 기관에 문의해 공식 답변으로 확정
- **계산 엔진** (`calc_engine/`, `POST /calculate`): 허용 연산 6개, 오류 규칙, 계산식·출처를 응답에 함께 담기
- **정답표와 테스트**: 정답을 두 방법(pandas / 파이썬 기본 csv)으로 계산해 같을 때만 기록, 일부는 상권분석서비스 사이트 표시값과 대조
- **대시보드용 데이터**: 점포 데이터 연결, 20곳·지도 80곳 데이터 파일, 업종별 점포 수·점포당 월매출
- **검증**: 펄이 답변 19개 정답 대조, 펄이 데이터 설명 문구 검수(B12), 배포 화면 사용자 흐름 점검

### 회고 — C 이성균
- **가장 크게 배운 것**: "숫자는 계산 엔진이 낸다"만으로는 부족했다. 펄이는 숫자를 하나도 지어내지 않았지만, 전년 대비를 물었을 때 전 분기 대비로 답했다. 검증은 **숫자와 질문의 뜻 둘 다** 봐야 한다.
- **다음에 다르게 할 한 가지**: 계산 규격을 **실제 데이터를 본 뒤에** 합의하겠다. 이번에는 데이터를 받기 전에 만든 규격(v1.0)이 실제 데이터와 달라서(월 단위를 가정했지만 실제는 분기 단위, 업종 이름도 다름) v1.1 제안이 따로 필요했다. 배운 것과 같은 교훈이다. 실제 데이터와 실제 뜻을 먼저 봐야 한다.
- **AI와 일하며 배운 것**: AI와 작업할 때는 내가 항상 요지를 파악하고 있어야 한다. 제출 전날 AI가 내 PC에서 돌린 결과만 보고 "다음 개선" 이슈를 만들었는데, 공개 서버에서 직접 확인해 보니 펄이는 이미 잘 답하고 있었다. AI는 체크리스트를 빈틈없이 채우는 쪽으로 일을 늘리기 쉬워서, 무엇이 실제 사용자에게 중요한지는 사람이 붙잡고 있어야 한다.

> **초안입니다.** 팀 TECH_SPEC의 "계산 엔진"·"데이터" 절로 옮겨 쓰기 위한 C 부분입니다. 기준: 2026-11-24 팀 레포 `main`.

## 1. 기술 스택
| 구분 | 사용 기술 | 고른 이유 |
|---|---|---|
| 계산 API | Python, FastAPI (`POST /calculate`, `GET /health`, 포트 8100) | B 서버와 같은 언어·프레임워크라 연결과 테스트가 쉬움 |
| 계산 | pandas | 분기·지역·업종 집계를 짧고 검증 가능한 코드로 씀 |
| 테스트 | pytest, FastAPI TestClient | 서버를 띄우지 않고 요청·응답까지 확인 |
| 데이터 | 서울 열린데이터광장 CSV (아래 5절) | 공공기관 데이터, 이용 제한 없음 |

### 1.1 의도적으로 쓰지 않는 것
| 쓰지 않는 것 | 이유 |
|---|---|
| LLM이 숫자를 계산하거나 고치게 하는 것 | 숫자는 계산 엔진에서만 나와야 근거를 댈 수 있음 |

## 2. 위치 (전체 흐름 속 C)
```
사용자 질문 → A 대시보드 → B 분석 서버(질문 해석·계획) → C 계산 엔진(숫자) → B(답변 문장) → A(화면)
```
- B는 계획(어떤 지표를, 어떤 조건으로, 어떤 연산으로)만 만들고, **숫자는 C만 만든다.**
- 대시보드에 미리 넣어 둔 숫자(리포트·지도·말풍선 답변)도 C가 만든 데이터 파일에서 나온다 (4절).

## 3. 계산 엔진
### 3.1 허용 연산
| op | 계산 | 비고 |
|---|---|---|
| `sum` | 합계 | |
| `avg` | 분기당 평균 = 기간 합계 ÷ 기간 내 분기 수 | 점포 수처럼 "쌓인 값"은 여러 분기를 물으면 이것으로 |
| `growth_rate` | 증감률 = (현재 − 기준) ÷ 기준 | 기준 값이 0이거나 없으면 `null` + 사유(`baseline_zero` / `baseline_missing`) |
| `ratio` | 비율 = 합계 ÷ 다른 합계 (예: 주말 매출 ÷ 총매출, 폐업 수 ÷ 전체 점포 수) | 성별·연령은 법인 매출이 빠진 합계로 나눔 |
| `share` | 전체 중 비중 | |
| `per_store` | 점포당 월평균 = 매출 ÷ (전체 점포 수 × 3개월) | 상권분석서비스 사이트와 같은 정의. 업종 조건도 함께 쓸 수 있음 |

### 3.2 검사 · 오류 규칙
| 코드 | 언제 |
|---|---|
| `COLUMN_NOT_FOUND` | 없는 지표·컬럼을 요청 |
| `UNSUPPORTED_OPERATION` | 허용 안 된 연산, 또는 그 지표에 쓸 수 없는 연산 (예: 점포 수에 `per_store`) |
| `INVALID_REQUEST` | 기간 형식이 틀리거나 분기 경계가 아님, 규격에 안 맞는 요청 |
| `NO_DATA` | 조건에 맞는 데이터가 없음 (예: 2030년) |
| `DATASET_NOT_FOUND` | 없는 데이터셋 |
| `INTERNAL_ERROR` | 예상하지 못한 오류 (숫자를 내지 않음) |

### 3.3 응답에 함께 담는 것
숫자만 주지 않고 **어떻게 나왔는지**를 함께 준다. B는 이것으로 답변의 근거와 주의 문구를 만든다.
- 적용 조건, 연산별 계산식(`methods[].formula`), 사용한 행 수, 데이터 출처·버전
- 안내(notes): 분기 단위로 계산함, 성별·연령은 법인 매출 제외, 업종 묶음 펼침(예: 카페=커피-음료), 지역에 포함된 동 개수, 점포 수는 프랜차이즈 포함

### 3.4 매출 표와 점포 표를 합치는 방법
두 표를 행끼리 붙이지 않고, **같은 조건(지역·분기·업종)으로 각각 집계한 뒤 나눈다.** 그래서 키가 겹쳐 행이 불어나는 문제가 생기지 않는다.

## 7. 테스트 전략
1. **정답표**: 정답을 두 방법(pandas / 파이썬 기본 csv)으로 따로 계산해 같을 때만 기록. 서교동은 상권분석서비스 사이트 표시값과 대조 (정답표 Q11·Q12)
2. **엔진 테스트** (`calc_engine/tests/`, 62개): 정답 대조, 오류 코드, 빈 파일·숫자 아닌 값 거부, CSV 셀 속 지시문은 데이터로만 취급
3. **B 연결 테스트** (`test_b_integration.py`): B 코드를 고치지 않고 B의 요청 생성 → C 계산 → B의 응답 검증까지 통과
4. **두 경로 일치**: 대시보드 데이터 파일의 점포당 매출 = 엔진 `per_store` 결과 (`test_industry_per_store_matches_engine`). 말풍선 답과 펄이 직접 답이 서로 다른 숫자를 말하지 않게 함
5. **실제 서버 회귀**: `calc_engine/scripts/pearl_eval.py`로 펄이에게 같은 질문 19개를 다시 보내 정답과 비교

출처: 서울 열린데이터광장 「상권분석서비스(추정매출-행정동)」 OA-22175, 「상권분석서비스(점포-행정동)」 OA-22172. 당월_매출_금액 합계(억 원), 신한카드 결제 기반 추정치라 실제 매출과 달라요. 점포 수는 프랜차이즈를 포함한 전체 점포, 점포당 매출은 분기 매출을 3으로 나눈 월평균이에요. 강남=역삼1동, 홍대=서교동, 건대=화양동, 이태원=이태원1동, 성수=성수1가1·1가2·2가1·2가3동 합산. 지도 위치는 행정동 경계의 중심(통계청 SGIS 행정동 경계 2026-10, 공공누리 제1유형 · 가공 vuski/admdongkor, CC BY 4.0). 지형은 실제 표고(AWS Terrain Tiles, SRTM 기반)를 높이 4배로 강조했고, 한강은 낮은 지대를 따라 뽑아 낸 물길이에요. 큰 건물은 각 상권 땅 위에 서 있고 높이만 매출을 나타내요(땅 높이는 매출에 더하지 않음). 리포트 20곳 주변 건물은 OpenStreetMap의 실제 건물 윤곽과 높이(층수)로 세웠고(© OpenStreetMap contributors, ODbL · 데스크톱에서만), 높이 정보가 없는 건물은 바닥 면적으로 추정했어요. 그 밖의 작은 건물들은 배경 장식이에요(낮에는 위성사진이 보이도록 숨겨요). 낮 지면은 위성사진(Contains modified Copernicus Sentinel data 2026, Sentinel-2 L2A 2026-05-31, AWS Open Data)을 지형에 입힌 것이에요. 낮에 건물과 데이터 탑에 입힌 외벽 사진은 ambientCG(CC0)의 텍스처예요(탑의 높이·색 의미는 그대로). 낮 지면의 그늘(주변광 가림, AO)은 같은 지형과 건물을 Blender Cycles로 미리 구워(bake) 입혔어요. 낮의 나무는 Poly Haven(CC0)의 나무 모델을 Blender로 그림처럼 구운 것이고, 위성사진에서 실제로 초록인 자리(리포트 20곳 주변)에만 심었어요. 데이터 탑 건물(아랫부분·몸통·꼭대기)은 팀이 Meshy로 만든 모델을 Blender로 가볍게 줄인 것이고, 몸통을 쌓는 개수로 높이(매출)를 그대로 나타내요. 밤에는 같은 건물의 유리창에 불이 켜지고 꼭대기가 유형 색으로 빛나요. 건물 색은 1위 업종 유형: 보라 = 시장·도매형(청과·수산·반찬·육류), 파랑 = 소비·서비스형.

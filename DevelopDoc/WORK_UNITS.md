# WORK_UNITS — 작업 단위 명세

> **예시 양식(초안)입니다.** 각자 자기 작업을 아래 틀로 적습니다. PR 번호를 기준으로 쓰면 빠릅니다 (PR 하나 = 작업 하나가 아니어도 됩니다).
> 구성: 운영진 예시 문서(WORK_UNITS.md) 구조를 줄여서 씀.

## 1. 작성 규칙
- **완료 조건은 관찰 가능하게** 씁니다. "구현했다"가 아니라 "이 명령을 실행하면 / 이 질문을 하면 이 결과가 나온다"
- 완료 조건 체크박스를 **전부 실제로 확인**해야 완료입니다
- 단위마다 **선행 작업**(먼저 끝나야 하는 것)과 **산출물**(파일·PR)을 적습니다
